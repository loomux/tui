# Changelog

All notable changes to `loomux`, the Loomux terminal client
(loomux/tui), are documented here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and the client
uses [Semantic Versioning 2.0.0](https://semver.org/spec/v2.0.0.html) on
its own version line, apart from the server's and the web client's: see
[`docs/release.md`](docs/release.md). Each release is a tag on `main`
whose binaries and notes are on its GitHub release; this file has the
curated milestones.

## [Unreleased]

What's coming waits in [`changes/`](changes/), one file per pull
request, until the next milestone folds it in here. The first is 0.1.0.
